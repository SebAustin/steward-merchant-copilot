# Orchestrator rulings for plan round 2 (binding on all three docs)

These resolve the cross-document contradictions plan-critic found in round 1 (67/100). Where a companion doc owns a topic, PLAN.md references it rather than restating it.

| # | Topic | Ruling | Owner doc |
|---|---|---|---|
| R1 | Doc ownership | AI-QUALITY.md owns models, routing, prompts, Untrusted Text format, evidence-ref grammar, eval commands, budgets and CI eval policy. DESIGN.md owns routes, pages, copy and tokens. PLAN.md owns architecture, data model, invariants, slices, CI/CD and probes. PLAN references the others by section and does not restate them. | all |
| R2 | Failed executions (D7) | `failed` splits into `failed_retryable` (PayPal 5xx, timeout before any response, 429) and `failed_final` (4xx business errors). A retry from `failed_retryable` goes back to `executing` with the **same** `PayPal-Request-Id`. | R3 | Approve atomicity (D1) | Approve and claim happen in one conditional UPDATE `proposed → executing` plus the approval insert, in one transaction. There is no standalone `approved` resting state for agent proposals. | PLAN |

| R5 | Model amounts (D10) | The model never authors money. Refunds carry `basis: full \| items \| shipping_only` plus `line_item_refs[]`, and code computes the amount. | R8 | Brief LCP (D19) | Brief renders a deterministic template from DB-cached data first (counts, amounts, deadlines). Model-written lines stream in afterwards. | PLAN + DESIGN |
| R9 | Routes (D17) | Use DESIGN's route table: `/enter`, `/` (Brief), `/queue`, `/invoices`, `/disputes`, `/risk`, `/audit`, `/policies`, `/settings`. | R21 | Probes (N7) | File **3** probe Disputes on Oct 6: one observe-only (P0-7), one for provide-evidence, one for accept-claim. # Round 5 rulings (final plan round; from plan-critic round 4, 80/100)

**Principle for this round: subtract, don't add.** The round-4 additions caused the regressions. Fix each defect by the smallest change or by deleting a mechanism. No new mechanism may be introduced beyond what these rulings name.
